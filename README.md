# Versionamiento Web - Arquitectura de Software

Sitio web informativo y de documentación desarrollado para la asignatura de **Arquitectura de Software** (Semestre 7) en la **Universidad Central del Ecuador** por el **Grupo 2**.

## 📑 Estructura de Páginas

El proyecto está configurado como una aplicación multipágina (MPA) utilizando Vite:

- **Inicio** (`index.html`): Portada y bienvenida.
- **Informe** (`informe.html`): Informe técnico del proyecto.
- **Investigación** (`investigacion.html`): Documentación e investigación teórica.
- **Presentación** (`presentacion.html`): Material y diapositivas de la presentación.
- **Recursos** (`recursos.html`): Enlaces, referencias y material complementario.

---

## 🛠️ Tecnologías

- [Vite](https://vitejs.dev/) - Entorno de desarrollo rápido y empaquetador
- HTML5, CSS3 y JavaScript moderno (ES Modules)
- [pnpm](https://pnpm.io/) - Gestor de paquetes eficiente

---

## 🚀 Instalación y Uso

### Prerrequisitos

Tener instalado [Node.js](https://nodejs.org/) y [pnpm](https://pnpm.io/).

### 1. Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd versionamiento-web
```

### 2. Instalar dependencias

```bash
pnpm install
```

### 3. Iniciar servidor de desarrollo

```bash
pnpm dev
```

El servidor estará disponible en `http://localhost:5173`.

### 4. Compilar para producción

```bash
pnpm build
```

Los archivos optimizados para producción se generarán en la carpeta `dist/`.

### 5. Previsualizar compilación de producción

```bash
pnpm preview
```
